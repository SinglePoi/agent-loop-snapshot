# @agent-loop-snapshot/instrumentation-anthropic

Capture Anthropic Messages API calls and consumed streams inside an Agent Loop Snapshot telemetry run.

```bash
npm install @agent-loop-snapshot/instrumentation-anthropic
```

Initialize `anthropicIntegration()` before loading the business module. Recording is metadata-only by default.

See the [SDK instrumentation guide](https://github.com/SinglePoi/agent-loop-snapshot/blob/master/docs/user-guide.md).
