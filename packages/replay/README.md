# @agent-loop-snapshot/replay

Replay recorded Agent runs in Mock, Verified, or Semantic modes, and compile traces into guarded Workflow IR.

```bash
npm install @agent-loop-snapshot/replay
```

Observation-only snapshots remain non-executable; execution eligibility is checked explicitly by the replay APIs.

See the [Workflow IR reference](https://github.com/SinglePoi/agent-loop-snapshot/blob/development-docs/docs/workflow-ir-v0.1.md).
