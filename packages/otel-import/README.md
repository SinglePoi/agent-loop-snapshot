# @agent-loop-snapshot/otel-import

Import OTLP/HTTP JSON `ExportTraceServiceRequest` files into redacted, observation-only snapshots.

```bash
npm install @agent-loop-snapshot/otel-import
```

Imported snapshots can be validated, inspected, and graphed; they cannot be replayed, resumed, or compiled as executable workflows.

See the [user guide](https://github.com/SinglePoi/agent-loop-snapshot/blob/master/docs/user-guide.md).
