# @agent-loop-snapshot/cli

The `alsnap` CLI validates, inspects, graphs, replays, imports OTLP JSON, and exports OTLP traces.

```bash
npm install --save-dev @agent-loop-snapshot/cli
npx alsnap --help
```

Commands return `0` on success, `2` for invalid or non-executable snapshot results, and `1` for usage or runtime errors.

See the [user guide](https://github.com/SinglePoi/agent-loop-snapshot/blob/master/docs/user-guide.md).
